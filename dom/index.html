Simple Multithreaded Template

A copyable template from the Awsm project — a WebGPU app skeleton running across three threads, all over one shared WebAssembly.Memory: a C app that owns all state and logic, a Rust renderer (AwsmRenderer), and a plain JavaScript page. No postMessage on any hot path.

Move the ball with WASD or the arrow keys; Space puts it back, and R loads the whole scene again. Stats (bottom left) shows each thread live; Settings (bottom right) sets the resolution and anti-aliasing.
